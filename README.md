# Монтажка

Видеоредактор, который работает целиком в браузере: файлы не загружаются на сервер.

- **ProRes** (в том числе 10 бит с камер Blackmagic) открывается через WASM-декодер `@mediabunny/prores`; H.264, HEVC, VP9 и AV1 декодирует сам браузер (WebCodecs).
- **Покраска на GPU** (WebGL2, текстуры в половинной точности): преобразование Blackmagic Film Gen 5 → Rec.709, экспозиция, баланс белого, колёса lift/gamma/gain, контраст, насыщенность, 3D LUT в формате `.cube`.
- **Таймлайн**: клипы встык, перестановка перетаскиванием, обрезка краёв, разрезание, масштаб щипком или Ctrl+колесо.
- **Экспорт** в MP4 (H.264 или HEVC/VP9/AV1, если H.264 недоступен) со звуком AAC/Opus.
- Работает на телефоне: адаптивная раскладка, жесты на таймлайне.

## Запуск

```bash
npm install
npm run dev
```

## Клавиши

| Клавиша | Действие |
|---|---|
| Пробел | Воспроизведение / пауза |
| S | Разрезать клип под плейхедом |
| Delete | Удалить выбранный клип |
| ← → | Кадр назад / вперёд |
| B | До / после покраски |

Двойной клик по ползунку или цветовому кругу сбрасывает его.

## Устройство

| Файл | Что делает |
|---|---|
| `src/project.ts` | Модель проекта: медиа, клипы, операции над таймлайном |
| `src/media.ts` | Импорт файлов через mediabunny, регистрация декодера ProRes |
| `src/renderer.ts` | WebGL2-рендер и шейдер покраски |
| `src/grade.ts` | Параметры покраски и чтение `.cube` |
| `src/player.ts` | Воспроизведение: видео по часам AudioContext, звук через Web Audio |
| `src/timeline.ts` | Таймлайн на canvas |
| `src/exporter.ts` | Экспорт: тот же рендер, что и в предпросмотре, кадр за кадром |

Предпросмотр и экспорт используют один `Renderer`, поэтому результат совпадает с тем, что видно на экране.
